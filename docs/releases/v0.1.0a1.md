# geofetch 0.1.0a1 — first public alpha

**Say what you want to analyse and where. geofetch works out which open geospatial data that needs, checks whether it is actually usable for your area and period, fetches only your area, organises and dates it, and writes down exactly how.**

```
geofetch ask "I heard a flood happened in Chitradurga in August 2026"
geofetch gui
```

## What's in this alpha

- **One question in.** Place and dates are read from plain English (the place becomes a boundary from OpenStreetMap), a project folder is created, and the data needs are worked out with a reason for each.
- **Feasibility before download.** Scene choice per tile and period, verdicts per month (for example "infeasible: clouds"), an automatic cloud-proof fallback, and a second source stitched in for years the first does not cover.
- **24 open sources**, including Sentinel-1/2, Landsat, MODIS, Copernicus DEM, WorldCover, JRC water, Hansen forest change, SoilGrids, WorldPop, CHIRPS and OpenStreetMap. Adding one is a YAML entry verified by `geofetch sources --check`.
- **Only your area** is transferred, as Cloud-Optimised GeoTIFFs and GeoPackages in one projection, with a static STAC catalogue, SHA-256 per file and a plain-language `REPORT.md`.
- **The app** (`geofetch gui`): ask → plan → fetching → project, running locally in your browser, with *Open in QGIS*.
- **Built-in AI** (23 MB, offline, no account): understands questions by meaning. On held-out questions understanding went from 11/17 with keywords alone to 16/17. It only chooses among existing rules and always says why.
- **Personal library**: files already on your disk are reused when that is exactly equivalent to downloading (byte-identical in tests); recipes share a project as one small file.

## Install

Python ≥ 3.12:

```
pip install geofetch-0.1.0a1-py3-none-any.whl
geofetch --version
```

## Known limits

Alpha: English-only understanding; no soil-moisture source yet; the area is set by a place name or a GeoJSON file (no drawing yet); OpenStreetMap building queries are limited to 2,000 km²; the first plan for a new area can take up to a minute.

Feedback and new data sources are very welcome — see CONTRIBUTING.md.
