# mapmise 0.1.0a1 — first public alpha

**Say what you want to analyse and where. mapmise works out which open geospatial data that needs, checks whether it is actually usable for your area and period, fetches only your area, organises and dates it, and writes down exactly how.**

Download the app for your computer below: Windows, macOS (Apple silicon or Intel) or Linux. Double-click it, and type
what you want to analyse.

## What's in this alpha

- **One question in.** Place and dates are read from plain English (the place becomes a boundary from OpenStreetMap), a project folder is created, and the data needs are worked out with a reason for each.
- **Feasibility before download.** Scene choice per tile and period, verdicts per month (for example "infeasible: clouds"), an automatic cloud-proof fallback, and a second source stitched in for years the first does not cover.
- **24 open sources**, including Sentinel-1/2, Landsat, MODIS, Copernicus DEM, WorldCover, JRC water, Hansen forest change, SoilGrids, WorldPop, CHIRPS and OpenStreetMap. Adding one is a YAML entry verified by `mapmise sources --check`.
- **Only your area** is transferred, as Cloud-Optimised GeoTIFFs and GeoPackages in one projection, with a static STAC catalogue, SHA-256 per file and a plain-language `REPORT.md`.
- **A desktop app for Windows, macOS and Linux**: ask → plan → fetching → project, running locally in your browser, with *Open in QGIS*. No Python needed.
- **Built-in AI** (23 MB, offline, no account): understands questions by meaning. On held-out questions understanding went from 11/17 with keywords alone to 16/17. It only chooses among existing rules and always says why.
- **Personal library**: files already on your disk are reused when that is exactly equivalent to downloading (byte-identical in tests); recipes share a project as one small file.

## Install

| Computer | Download |
|---|---|
| Windows 10/11 (64-bit) | `Mapmise-0.1.0a1-windows-x64-setup.exe` (or the portable `.zip`) |
| Mac, Apple silicon (M1 or newer) | `Mapmise-0.1.0a1-macos-arm64.dmg` |
| Mac, Intel | `Mapmise-0.1.0a1-macos-x64.dmg` |
| Linux (64-bit) | `Mapmise-0.1.0a1-linux-x64.AppImage` (or `.tar.gz`) |
| Python ≥ 3.12, any system | `pip install mapmise-0.1.0a1-py3-none-any.whl` |

**The installers are not code-signed yet**, so the first start shows a warning:
on Windows click *More info → Run anyway*; on macOS open *System Settings → Privacy & Security* and click
*Open Anyway*. `SHA256SUMS.txt` lists the checksum of every file. Every build was tested on its own operating
system before release, including a real download.

## Known limits

Alpha: installers are unsigned (see above); English-only understanding; no soil-moisture source yet; the area is set by a place name or a GeoJSON file (no drawing yet); OpenStreetMap building queries are limited to 2,000 km²; the first plan for a new area can take up to a minute.

Feedback and new data sources are very welcome — see CONTRIBUTING.md.
