## Mapmise 0.1.0a2

This pre-release introduces the Mapmise logo — a folded map in the shape of an M, marked with contour lines — as
the application icon on Windows, macOS and Linux, in the application itself and in the documentation.
Functionality is unchanged from 0.1.0a1; see the [0.1.0a1 release notes](https://github.com/AiM0-create/mapmise/releases/tag/v0.1.0a1)
for a full description.

### Installation notes

These installers are not yet code-signed, so the operating system asks for confirmation on first launch:

- **Windows:** choose **More info**, then **Run anyway**.
- **macOS:** open **System Settings → Privacy & Security** and choose **Open Anyway**.

Every build was produced by the repository's public release workflow and tested on its own operating system before
publication, including a live acquisition and the application window.
