## Mapmise 0.1.0a4

This release addresses the findings of the first real-world test on Windows.

- **Immediate start screen.** The window opens at once and shows progress while the data engine loads. On Windows
  the first start can take up to a minute while the system checks the newly installed app; later starts are faster.
- **One copy only.** Starting Mapmise again — even while it is still loading — brings the existing window forward
  instead of opening another copy.
- **Visible planning.** Each step is shown as it happens — finding the place, checking each dataset — with the
  elapsed time and a Cancel button.
- **Large areas.** Areas above 50,000 km² must be confirmed before planning. Above 100,000 km², Mapmise plans
  area-wide products such as forest change, land cover and MODIS vegetation rather than scene-by-scene imagery, which
  at that scale would take hours to plan and terabytes to download. A question such as *forest loss in Brazil* now
  receives an answer in seconds.
