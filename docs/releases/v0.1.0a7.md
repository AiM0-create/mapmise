## Mapmise 0.1.0a7

A quality release, from an end-to-end test of all fourteen analyses on one area: every analysis planned, and ten
were acquired for real — 186 files with no failures.

- **One projection for everything.** Vector layers (roads, facilities, boundaries, waterways) are now delivered in
  the project's projection, like the rasters, so they overlay directly in any tool.
- **Empty files are no longer silent.** Each raster records the share of your area holding valid values. Files with
  none — MODIS land temperature under monsoon cloud, for instance — are listed in the acquisition report.
- **Clearer gaps.** When a product exists but is not published for the period you asked about, the plan names it,
  gives the years it covers and suggests a period.
- **Report a problem.** Settings → About shows the version and your system, opens a GitHub form with the version
  filled in, and opens the folder with Mapmise's log.
