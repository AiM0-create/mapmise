## Mapmise 0.1.0a5

- **Linux start-up.** In 0.1.0a4, starting the Linux AppImage from the applications menu or with a double-click could close
  immediately without opening anything, on systems without the web view used for the app's own window. Mapmise now
  checks for that component first and otherwise opens in your default browser; if the window cannot open for any
  other reason, it also falls back to the browser. The Linux release build now tests this start-up path, as the
  Windows and macOS builds already did.
- **No more dead ends for unclear questions.** When a question matches no analysis with confidence — for example
  *Expansion of Noida* — Mapmise asks which analysis you mean, with the likeliest first (*Urban growth*), instead of
  stopping with an error. One click plans it. An unclear question no longer triggers a place lookup or creates a
  project folder.
