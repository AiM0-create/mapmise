## Mapmise 0.1.0a5

A corrective release for Linux.

- In 0.1.0a4, starting the Linux AppImage from the applications menu or with a double-click could close
  immediately without opening anything, on systems without the web view used for the app's own window. Mapmise now
  checks for that component first and otherwise opens in your default browser; if the window cannot open for any
  other reason, it also falls back to the browser. The Linux release build now tests this start-up path, as the
  Windows and macOS builds already did.

Windows and macOS users are not affected; this release is identical for them apart from the version number.
